# Tickr for Palantir

This is the repository for the passion project [Tickr](https://github.com/facebook/create-react-app), a proof-of-concept financial analytics dashboard for finance. Tickr is modelled on Palantir owing to their meteoric stock performance and exciting ventures as a tech company.

Simply, Tickr serves a purpose for roles such as, but not limited to, Traders, Analysts, Portfolio Managers.
